# Trosa Byggtjänst — kompletta hemsidan

## Ladda upp till GitHub Pages

1. Packa upp filen och ladda upp allt innehåll till ditt repository. `index.html` ska ligga i roten tillsammans med `styles.css`, `script.js`, de andra HTML-filerna och mappen `assets`.
2. Behåll filnamn och mappar. Bilderna finns i `assets/images`, typsnittet i `assets/fonts`.
3. Välj **Settings → Pages → Deploy from a branch**, huvudbranchen och **/ (root)**. Spara och invänta publiceringen.

Alla bild- och sidlänkar är relativa och fungerar även under repositorynamnet. Döp inte startsidan till `index (1).html` och ladda inte bara upp HTML-filen utan bildmappen.

## Kontakt

Kontaktformuläret öppnar ett mejlutkast i besökarens eget e-postprogram. Besökaren granskar och skickar själv. Inget skickas automatiskt eller lagras av formuläret. Det finns också kopiering av förfrågan och direkta telefon- och mejllänkar.

## Egen domän och sökmotorer

Vid byte av domän: ersätt `https://trosa-byggtjanst.carlzzon121.chatgpt.site` med den slutliga adressen i HTML-sidornas canonical, Open Graph och strukturerade data samt i `sitemap.xml` och `robots.txt`. Aktivera HTTPS hos webbhotellet eller GitHub Pages.
